# GMC - The Reading Room

The Reading Room is a simple book library web application built with React and React-Bootstrap. It showcases three classic literary works in a clean, elegant, and responsive layout.

This project was created as part of a GMC React checkpoint to practice building components and using React-Bootstrap.

## Features

- Responsive navigation bar with Home, Our Books, and About links.
- A welcoming heading and introduction.
- Three book cards featuring book covers, titles, authors, publication years, genres, and descriptions.
- Interactive buttons displaying additional information about each book.
- A dedicated About section and footer.
- Custom styling with a classic literary theme.
